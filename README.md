# Σ-PAS grant materials

Public grant-application materials for the Σ-PAS verification program
(Or4cl3 AI Solutions, Dustin Groves). These files exist so funder forms
that require a link can point at them.

- `taif-budget.csv` — Transformative AI Fund (EA Funds) $20,000 budget
  breakdown, linked from the TAIF application form.
- `iliad-open-call-proposal.md` — Proposal to the Iliad Open Call for
  Research Projects, linked from the Iliad application form.
